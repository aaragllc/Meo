# <persona-slug> - operating lessons

*(This persona's copy of the platform lessons file. READ THIS before
touching any platform for this persona.)*

Lessons are earned in production and recorded the day they are learned,
each with its date. They are operating rules, not advice: when a lesson
here conflicts with a generic instinct, the lesson wins. Platform-wide
rules live in `../../POLICY.md` and the specs; this file holds what is
specific to operating THIS persona's accounts - editor hazards, session
quirks, sign-in paths that must never be automated, posting techniques
that mangle text when done the obvious way.

## How to add a lesson

- One entry per lesson: what happened, the date, what to do instead.
- If a lesson changes how a channel is operated, also check whether the
  channel's adapter spec (from `../../templates/channel-adapter.md`) or
  the failure taxonomy (`../../SPEC-run-log.md`) needs a matching entry.
- Never record credentials, codes, or the owner's identifying details
  here - lessons reference accounts by persona name only.
